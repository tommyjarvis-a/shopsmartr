Theme-sheet preview subsets (Happy Wife Helper v0.2.5)

Each file holds only the glyphs needed to show the five theme names and "Aa" in that theme's heading face,
at its heading weight. They load only when the Theme sheet opens (about 20 KB for all five), so the sheet
doesn't download every full theme font.

Made with fontTools (instancer + subsetter) from the files one level up. They are Modified Versions under
the SIL Open Font License 1.1, so they carry their own family names ("HWH Preview ...") and not the
original (or any Reserved) font names. Licences: see ../LICENSE-*.txt.

  nunito-preview.woff2            Nunito 800            ../LICENSE-nunito-variable.txt
  inter-preview.woff2             Inter 700             ../LICENSE-inter-variable.txt
  fraunces-preview.woff2          Fraunces 600          ../LICENSE-fraunces.txt
  quicksand-preview.woff2         Quicksand 700         ../LICENSE-quicksand-variable.txt
  dm-serif-display-preview.woff2  DM Serif Display 400  ../LICENSE-dm-serif-display.txt
